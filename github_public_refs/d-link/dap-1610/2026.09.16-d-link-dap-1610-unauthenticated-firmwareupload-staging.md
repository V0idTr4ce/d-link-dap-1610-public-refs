# Unauthenticated FirmwareUpload Stages User-Controlled Data on D-Link DAP-1610

- Published: 2026-09-16
- Last updated: 2026-09-16
- Supplier: D-Link
- Product: DAP-1610
- Affected version(s): DAP-1610_FW105B01.bin
- Vulnerability type: Missing Authentication for Critical Function (CWE-306)
- Affected component / endpoint / code path:
  - HNAP FirmwareUpload action
- Credits: Zhou Ao, Yin Luxing, Yuan Zixuan, Liu Xin, @Nebusec

## Summary
The DAP-1610 firmware accepts the HNAP FirmwareUpload action without authentication and stages client-supplied upload data in a local firmware-image file. This behavior was reproduced on the affected build.

## Impact
An unauthenticated user with access to the device management interface can cause the device to stage attacker-controlled firmware-upload data.
